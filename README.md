#  📄DocuDrop
> Your Personal Lab Assistant. Screenshots, automated.

## 💡 About This Project

**DocuDrop** is a lightweight desktop productivity tool built with Python, designed to solve a common and frustrating problem: the constant app-switching required to add screenshots to lab reports and documents. Born from a personal need to streamline this process, DocuDrop monitors your computer for new screenshots and automatically adds them to a specified Word document, saving you time and letting you stay focused on your work.

It features three versatile modes to fit any workflow: two "File Modes" (Clipboard/Folder) for adding images to a closed document, that pastes screenshots directly into your open Word document at your cursor.

---


## ✨ Features

DocuDrop is built to be flexible and smart, with three distinct modes to handle any situation:

* **1. Clipboard Mode (File is Closed):**
    * **What it does:** Monitors your clipboard. When you copy a new image (`Win+Shift+S`), it's automatically saved to the *end* of your selected `.docx` file.
    * **Best for:** Rapid-fire screenshots when you're not actively writing.

* **2. Folder Mode (File is Closed):**
    * **What it does:** Monitors a specific folder. Any new image file saved or moved into this folder is automatically added to the *end* of your `.docx` file.
    * **Best for:** Working with screenshot tools that auto-save to a directory (like `Win+PrtScn`).

## 🚀 How to Use

1.  Start the **DocuDrop** application.
2.  Click **"Select .docx File"** to choose your target Word document.
3.  Select your desired mode from the switch:
    * `Clipboard` (for a closed file)
    * `Folder` (for a closed file)
    * `Live Word` (for an open file)
4.  If you chose **"Folder"** mode, click **"Select Folder"** to pick which folder to watch.
5.  Click the **"Start"** button and begin working!
6.  Click **"Stop"** when you're finished.
